# خطة محتوى محفظتي برو المستقلة

محفظتي برو مجاني وبدون اشتراك. الجمهور: أصحاب محلات المحافظ وخدمات الدفع في مصر. الإنتاج مستقل عن Visibly؛ لا حاجة إلى رابط تغذيته أو اشتراكه.

## سياسة التنفيذ
- اختر سؤالًا عمليًا واحدًا لكل مقال، مع مثال أو قائمة تنفيذ، وتجنب تكرار صفحات موجودة.
- افحص site/features.html والتطبيق قبل نسبة أي ميزة إليه. لا تدّعِ الاتصال المباشر بالشركات أو تنفيذ التحويلات أو صلاحيات موظفين غير مؤكدة.
- المقالات تنظيمية وليست نصيحة مالية أو قانونية. الرسوم والحدود والأكواد تحتاج مصادر رسمية حية وتاريخ تحقق.
- العناوين والكلمات المستهدفة اقتراحات تحريرية، وليست نتائج أداة قياس لحجم البحث.
- استخدم القالب الحالي وصور البرنامج. أضف وصفًا وcanonical وArticle metadata وروابط داخلية وبطاقة في الفهرس وخريطة الموقع.
- اختبر الروابط والعناوين والبيانات المنظمة ومعاينة الموبايل. لا تغيّر التطبيق ضمن مهام المحتوى.
- احفظ التغييرات على فرع تجريبي وطلب تعديل قابل للمراجعة. لا تدمج أو تنشر تلقائيًا قبل مراجعة النسخة.
- لا تُنشئ روابط تبادل مصطنعة أو وعود ترتيب. لا تغيّر التواريخ بلا تعديل حقيقي.
- وضّح استخدام مساعدة الذكاء الاصطناعي دون أسماء أو خبرات مختلقة.

## قائمة الموضوعات التالية
1. توثيق المصروفات والمسحوبات الشخصية بعيدًا عن العمولة.
2. سجل العمليات المعلقة: الحقول ومسؤول المتابعة.
3. الفرق بين تقرير Excel وملف النسخ الاحتياطي.
4. تسمية الخطوط والعملاء لمنع أخطاء الاختيار.
5. مراجعة أول أسبوع بعد استخدام البرنامج.
6. التحقق من العملية قبل تسجيلها: المرجع والحالة.
7. مراجعة الحسابات من الموبايل والكمبيوتر: ما الذي تتحقق منه؟
8. تنظيم أرشيف الإيصالات ومراجع العمليات.
9. قراءة تقرير العمليات دون خلط إجمالي الحركة بالإيراد.
10. توثيق تصحيح القيود مع الاحتفاظ بسبب التصحيح.
11. استكمال دليل الإقفال الحالي بمثال تطبيقي بدل إنشاء مقال مكرر.
12. تحديث أدلة شركات المحافظ عند تغير المصدر الرسمي بدل إعادة إنتاجها.

## القياس
التحليلات الحالية تستخدم GA4 وأحداث click_start_free وclick_download. هذه الأحداث تقيس ضغطات فقط، وليست تسجيلات مكتملة. متابعة الظهور والنقرات والكلمات تتطلب وصول Search Console غير المتاح ضمن هذا التعديل. لا نعرض أرقامًا تقديرية على أنها نتائج فعلية.

## حدود الاستقلال
الكتابة والمراجعة تتم عبر مهام ChatGPT المتكررة عند توفر الوصول للمستودع. GitHub وحده لا يولّد نصوصًا جديدة دون نموذج أو كاتب. لا يترتب على هذا الكود استخدام API مدفوع جديد. اشتراك Visibly لا يلغى تلقائيًا، وحذف سره من GitHub إجراء مستقل يمكن للمستخدم القيام به بعد الاستغناء عنه.

# ربط Visibly بمحفظتي برو عبر JSON Feed

## الإعداد
تم تفعيل RSS/JSON Feed من حساب المستخدم. احفظ رابط JSON كاملًا في Repository secret باسم `VISIBLY_FEED_URL` داخل Settings → Secrets and variables → Actions. لا نحتاج مفتاح WordPress أو VISIBLY_SITE_ID لهذا المسار.

## التشغيل
يعمل سير Fetch Visibly drafts for review عند تحديث ملفات الاستيراد في فرع codex/visibly-draft-integration لاختبار الاتصال، ويمكن تشغيله يدويًا بعد دمج الطلب من Actions → Run workflow. صلاحياته قراءة فقط؛ لا يعدّل الموقع.

بعد النجاح حمّل حزمة visibly-review من Artifacts (صلاحيتها 7 أيام). عدد المقالات يظهر في السجل. قد تكون التغذية فارغة؛ تعرض مقالات منشورة في Visibly، ولا تضمن نشرها على موقعنا.

## حدود الاستيراد
المخرجات ملفات JSON خارج site/ للمراجعة، وتحتفظ بالمحتوى والروابط كما وردت. تعامل معها كنص غير موثوق. لا ترفعها إلى الموقع مباشرة. يلزم لاحقًا مراجعة أول مقال وتحويل HTML وتنظيفه ضمن القالب الحالي، وإضافة البطاقة وخريطة الموقع واختبار معاينة Cloudflare قبل النشر.

يقبل المستورد HTTPS على heyvisibly.com وwww.heyvisibly.com فقط، ويرفض التحويلات والصفحات الإضافية حتى نراجع عنوانها. يتوقف بدل تصدير بيانات جزئية عند تغير صيغة التغذية أو تجاوز حجم 5MB أو وجود تكرار. لا يطبع الرابط السري أو تفاصيل استجابة الخطأ.

تفعيل التغذية مرتبط بشروط شبكة تبادل الروابط الظاهرة في لوحة Visibly؛ تجهيز الاستيراد لا يقيّم جودة الروابط ولا يضمن نتائج البحث.

## الاختبارات
`python -m unittest discover -s tests -p 'test_visibly_drafts.py' -v`

نجحت 9 اختبارات محلية تشمل التحقق من النطاق والتحويلات وحفظ HTML كبيانات وأسماء الملفات الآمنة والتغذية الفارغة ورفض صفحات غير مراجعة، بالإضافة إلى اختبارات مساعد API القديم. الاتصال الحقيقي يتأكد من نتيجة GitHub Actions، وليس الاختبارات المحلية.
